# Task & Productivity Manager

A Python-based productivity dashboard that helps users organize daily activities, manage deadlines, prioritize work, and monitor task completion.

## Features

- Create, edit, and delete tasks
- Set task categories, priorities, and due dates
- Track Pending, In Progress, and Completed tasks
- Search and filter tasks
- Monitor overdue tasks and completion progress
- Visualize productivity using interactive charts
- Store tasks in an SQLite database

## Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly

## Installation

1. Clone this repository.
2. Open the project folder in your terminal.
3. Create and activate a virtual environment if desired.
4. Install the dependencies:

   `pip install -r requirements.txt`

5. Run the application:

   `streamlit run main.py`

## Database

The application automatically creates `tasks.db` on first launch.
